Windows용 무료 내려받기 안드로이드 테스트 참여

Windows 10·11 (64비트) · 안드로이드 8.0 이상. 안드로이드 앱은 Google Play 출시 전 테스트 중이라, 메일을 보내 주시면 초대해 드려요. Microsoft Store와 Google Play에도 곧 올라가요.

기본 기능은 계속 무료예요. 캐릭터·캘린더 스킨 같은 꾸미기는 프리미엄(월 2,900원 / 연 31,000원 예정, 부가세 포함)인데, 지금은 베타 기간이라 모두 무료로 열려 있어요. 무료 체험이 끝나도 저절로 결제되지 않아요.
